Catalogue API reference

The Northwind Catalogue API returns book data as JSON. All requests use HTTPS and require an API key sent in the X-Api-Key header.

Authentication

Create a key in your account settings. Keys are 32 characters long and can be revoked at any time.

curl -H "X-Api-Key: YOUR_KEY" https://api.northwind.example/v1/books

List books

GET /v1/books returns a paginated list.

ParameterTypeDefaultDescription
pageinteger1Page number
per_pageinteger20Results per page (max 100)
genrestring—Filter by genre
in_stockbooleanfalseOnly books currently in stock
import requests

resp = requests.get("https://api.northwind.example/v1/books",
                    headers={"X-Api-Key": KEY}, params={"genre": "Poetry"})
for book in resp.json()["data"]:
    print(book["title"], book["price"])

Rate limits

Each key may make 600 requests per minute. Exceeding the limit returns HTTP 429 with a Retry-After header.

Errors

  1. 401: missing or invalid key.
  2. 404: the book doesn't exist.
  3. 429: rate limit exceeded.
